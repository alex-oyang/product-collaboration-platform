# 项目产品协作平台

面向产品经理与跨岗位评审成员的本地原型发布、版本管理和批注协作系统。前端使用 Vue 3、TypeScript 与 Tailwind CSS；本机服务负责登录、权限、产品数据、上传文件和操作记录的持久化。

## 本地运行

```powershell
npm install
npm run dev
```

- 前端开发地址：`http://127.0.0.1:5178/`
- 本机 API：`http://127.0.0.1:3018/`

生产构建与本机启动：

```powershell
.\scripts\start-local.ps1
.\scripts\status.ps1
```

`start-local.ps1` 会在 `dist/` 不存在时先执行 `npm run build`，然后以隐藏窗口启动本项目 Node 服务。PID 与日志保存在项目自己的 `runtime/` 目录。生产入口为 `http://127.0.0.1:3018/`。首次启动会在 `data/` 生成本机演示数据；该目录已被 Git 忽略。

停止服务：

```powershell
.\scripts\stop.ps1
```

停止脚本只会处理 PID 文件指向、且命令行明确属于本项目 `server/index.mjs` 的 `node.exe`，不会按端口或进程名批量结束其他 Node 服务。

## 上传原型与源码包

- 单个 HTML 可以直接上传；包含脚本、样式和图片时请上传 ZIP，并让入口文件位于 ZIP 根目录或唯一的顶层目录中。
- Vite 项目必须使用相对资源路径构建，在 `vite.config.ts` 中设置 `base: './'` 后再执行构建并压缩 `dist`。默认的绝对 `/assets/...` 会指向评审系统自身根目录，无法从原型版本目录加载。
- 支持 `.tar.gz` / `.tgz` 源码包。当前会识别 Next.js 项目，在本机安装依赖、执行生产构建，并把可静态预渲染页面发布为版本；动态 API 页面不作为原型入口。
- 源码构建会运行项目的 Next.js 配置，只应上传可信项目。迁移到公司服务器后可设置 `PROTOTYPE_ALLOW_SOURCE_BUILDS=0` 关闭源码构建，只接收 HTML 与静态 ZIP。
- 安全预览通过短时签名凭证读取当前版本资源；模块资源使用匿名跨域加载，这不会替代 Vite 的相对 `base` 配置。

## 权限摘要

- 产品岗位和超级管理员可见“产品上传”；其他岗位不显示入口，直接调用接口也会被拒绝。
- 产品负责人或超级管理员可以编辑、上下架、移交、授权、回收和回滚产品。
- 已授权成员可查看上架产品、添加批注和回复，并且只能编辑或删除自己的文字。
- 超级管理员可管理账号和全部批注，并查看全量操作记录。
- 更新访问码或访问码到期只影响后续兑换，不影响已经授权的成员；负责人可单独收回成员权限。

## 开启内网访问

默认只监听本机回环地址。确认已修改全部演示口令后，可在 PowerShell 中运行：

```powershell
.\scripts\start-lan.ps1
```

`start-lan.ps1` 会以 `HOST=0.0.0.0`、`PORT=3018` 启动并显示安全警告。同事通过 `http://你的内网IP:3018/` 访问。脚本不会自动修改 Windows 防火墙；放行范围与公司网络策略需要在实际部署时单独确认。
